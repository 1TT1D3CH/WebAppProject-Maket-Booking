# เปลี่ยนเลข PromptPay เป็น 0965572213

## เป้าหมาย
ในป๊อปอัปจองแผง (กล่อง "ยอดที่ต้องโอน") ตอนนี้แสดง `PromptPay: 081-999-8888`
ให้เปลี่ยนเป็นเลขใหม่ **0965572213** (แสดงผลเป็น `096-557-2213`) ทุกจุดในแอป

## ขั้นตอน
1. ค้นหาเลขเก่าทุกรูปแบบในโปรเจกต์ (ยกเว้น node_modules, dist, build)
   ```
   grep -rn -E "081-?999-?8888|0819998888|66819998888" . --exclude-dir={node_modules,dist,build,.git}
   ```
   และค้นคำว่า `promptpay`, `promptPay`, `PROMPTPAY` (ไม่สนตัวพิมพ์) เพื่อหาค่าตั้งต้นที่เก็บไว้ที่อื่น
2. แทนที่ทุกจุดที่เจอ:
   - ข้อความ UI ที่ hardcode: ใช้ `096-557-2213`
   - ค่าที่ใช้สร้าง QR / payload / config: ใช้ตัวเลขล้วน `0965572213`
     (ถ้าโค้ดแปลงเป็นรูปแบบ `66965572213` เอง ไม่ต้องแก้ส่วนแปลง)
   - ไฟล์ env: `VITE_PROMPTPAY_NUMBER=0965572213` ใน `.env`, `.env.example`, `.env.production` (ถ้ามี)
     และบอกให้ผมอัปเดตค่าเดียวกันใน environment ของที่ deploy ด้วย (ถ้ามีใช้)
   - ค่าเริ่มต้นใน Firebase / seed / ตัวแปร default ของ markets doc (`settings.promptPayId` หรือชื่อใกล้เคียง)
3. ถ้าแอปมีหน้าตั้งค่าตลาดใน admin ที่แก้เลข PromptPay ได้แล้ว
   - ห้ามเขียนทับข้อมูลใน Firestore ด้วยสคริปต์ ให้บอกผมว่าต้องไปกดแก้ในหน้า admin แทน
     เพราะค่าใน Firestore จะชนะค่า default ในโค้ด
4. ถ้ายังไม่มีหน้า admin สำหรับเลขนี้ ให้แก้แค่ในโค้ด/env ตามข้อ 2 พอ (ไม่ต้องสร้างหน้าใหม่ในงานนี้)
5. ถ้ามีการสร้าง QR PromptPay ให้ตรวจว่า QR ที่สร้างใหม่ใช้เลข 0965572213
   (สแกนด้วยแอปธนาคารแล้วชื่อผู้รับต้องตรง) และ unit test ที่อ้างเลขเก่าให้อัปเดตด้วย

## ตรวจงาน
- รัน grep ในข้อ 1 อีกครั้ง ต้องไม่เจอเลขเก่าเหลือ
- `npm run build` ผ่าน
- เปิดป๊อปอัปจองแผง ต้องเห็น `PromptPay: 096-557-2213`
