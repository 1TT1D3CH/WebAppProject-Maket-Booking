 1. ภาพรวมโปรเจกต์
===============================================================================

เว็บแอปจองแผงตลาด มีผู้ใช้ 3 บทบาท
  - tenant (ผู้เช่า/ลูกค้า): ดูผังตลาด เลือกแผง กรอกข้อมูลและแนบสลิปเพื่อจอง รับแจ้งเตือน
  - admin (ผู้ดูแลผัง): จัดผังแบบลากวาง (Admin Builder) จัดการแผง โซน วัตถุในผัง
  - owner (เจ้าของตลาด): สิทธิ์เหมือน admin และแก้ข้อมูลผู้ใช้ได้

เทคโนโลยี
  - Vue 3 (<script setup>) + Pinia + Tailwind CSS 3 + Vite 5
  - Firebase: Authentication (Email/Password, Google), Firestore
  - ไอคอน: lucide-vue-next
  - ทดสอบ: node:test (ฟังก์ชันวันที่), Firestore emulator (rules)

โครงสร้างไฟล์หลัก
  src/App.vue                         หน้าหลัก สลับโหมดลูกค้า/admin และรวม modal ทั้งหมด
  src/stores/                         authStore, marketStore, notificationStore (Pinia)
  src/services/firebaseService.js     อ่าน/เขียนผังและ transaction การจอง
  src/components/Admin/               StallCanvas (ผังลากวาง) และ modal แก้ไขแผง/วัตถุ/โซน/ตลาด
  src/components/canvas/              แถบเครื่องมือผัง (CanvasToolbar และส่วนย่อย)
  src/components/Customer/            ผังฝั่งลูกค้า และฟอร์มจอง
  src/components/Auth/                เข้าสู่ระบบ/สมัคร, ขอเบอร์โทร, แจ้งเตือน, สลับบทบาททดสอบ
  src/utils/                          date, authErrors, keyboard, icons
  firestore.rules                     กฎสิทธิ์ของ Firestore
  tests/                              date.test.mjs, firestore.rules.test.mjs
  docs/CODE_REVIEW.txt                รายงานตรวจโค้ด (ฐานของงานแก้ไขทั้งหมด)
  prompt/                             prompt ที่ใช้สั่งงาน AI และสถานะการใช้งาน

 8. คำสั่งที่ใช้บ่อย และวิธีทดสอบ
===============================================================================

  npm install            ติดตั้ง dependency
  npm run dev            รันเครื่อง dev (ต้องมี .env)
  npm run build          build production (ผ่านทุก commit; มีคำเตือนขนาด bundle > 500 kB ตั้งแต่เดิม)
  npm run test:unit      ทดสอบฟังก์ชันวันที่ (44 ข้อ ผ่านทั้งหมด)
  npm run test:rules     ทดสอบ firestore.rules ด้วย emulator (ต้องติดตั้ง firebase-tools)

ทดสอบด้วยมือที่สำคัญ
  - ไม่ล็อกอิน: เห็นแค่หน้าลูกค้า เข้า Admin Builder ไม่ได้
  - สมัครด้วยอีเมล / Google: ได้ role tenant, ถูกขอเบอร์โทรครั้งแรก, รีเฟรชแล้วยังล็อกอินอยู่
