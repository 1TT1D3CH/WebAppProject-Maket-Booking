# เช็กลิสต์ฟีเจอร์ระบบจองแผงตลาด (Dynamic Market Stall Booking System)

สถานะประเมินจากรายงาน code review และ prompt ที่ทำไว้แล้วในโฟลเดอร์นี้ ยังไม่ได้เปิดโค้ดจริง
(repo ยังไม่ได้เชื่อมกับโปรเจกต์) ถ้าข้อไหนมีแล้วจริง ๆ ก็ติ๊กผ่านได้เลย

**สัญลักษณ์สถานะ**
- ✅ มีแล้ว
- 🟡 มีบางส่วน หรือมีแต่ยังมีบั๊ก (ส่วนใหญ่มี prompt แก้ไว้แล้ว ระบุไว้ในวงเล็บ)
- ❌ ยังไม่มี

**ลำดับความสำคัญ**
- **P0** ต้องมีก่อนเปิดให้คนใช้จริง
- **P1** ควรมีในช่วงแรกหลังเปิด
- **P2** ทำทีหลังได้ ช่วยให้ระบบดีขึ้น

## ลำดับที่แนะนำ

1. ทำ `fix-prompts-th.md` ระยะ 1 ถึง 3 ให้จบก่อน เพราะครอบคลุม P0 เกือบครึ่ง
2. P0 ที่ยังไม่มี prompt (ควรทำต่อจากระยะ 3):
   - ลืมรหัสผ่าน
   - หน้า "การจองของฉัน"
   - หมดเวลาชำระเงินแล้วปล่อยแผงคืน
   - ตั้งวันเปิด-ปิดตลาด
   - ค้นหา/กรองการจองในหน้า admin
   - หน้าจัดการผู้ใช้ของ owner
   - ยอมรับกติกาก่อนจอง และหน้านโยบายความเป็นส่วนตัว
   - เขตเวลาไทย
3. จากนั้นค่อยไล่ P1 โดยเริ่มจากแจ้งเตือน LINE/อีเมล, ยกเลิกเอง, ใบเสร็จ และแดชบอร์ด
