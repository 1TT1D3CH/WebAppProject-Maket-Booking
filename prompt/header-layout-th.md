## ปัญหาที่เห็นจากภาพหน้าจอ (จอกว้าง ~1350px)

- ป้าย "Online" ถูกบีบจนตัวอักษรเรียงแนวตั้ง ("O / nli / ne") และมีคำว่า "ขนาดผัง" ลอยอยู่ใต้ป้ายโดยไม่มีความหมาย
- แถวบนอัดทุกอย่างไว้ด้วยกัน: โลโก้, ป้ายออนไลน์, แท็บ 6 อัน, ปุ่มธีม, การจองของฉัน, กระดิ่ง, Owner tester001 ไม่มีช่องหายใจ
- แท็บที่เลือก (Admin Builder) มีทั้งพื้นสีม่วงและขอบขาวหนา ดูหนักกว่าส่วนอื่นมาก
- แถวสอง: ชิปสถิติ 5 อันกับปุ่ม 6 อันแย่งที่กัน ปุ่มแต่ละอันคนละสี (ม่วง เขียว ชมพู ฟ้า) ไม่มีลำดับความสำคัญ
- "รีเซ็ตผัง" เป็นลิงก์ขีดเส้นใต้ชิดขอบจอ ทั้งที่เป็นการกระทำอันตราย กดพลาดง่าย
- "เพิ่มแผง" และ "20×20ม." ซ้ำกับแถบเครื่องมือบนผัง (ตาม mobile-tablet-ux ข้อ 7 ต้องเหลือที่เดียว)

```
มือถือ (<768px) ตาม mobile-tablet-ux ส่วน 2: header = แบรนด์ + 🔔 + ☰, แท็บไปอยู่ในลิ้นชัก/bottom nav
  page bar: [สถิติ ▾]  ●  [บันทึก]  ที่เหลืออยู่ใน ⋯
```

## Prompt (คัดลอกทั้งก้อน)

```
คุณคือนักพัฒนา Vue 3 + Tailwind CSS ที่ทำงานใน repo ของ "Dynamic Market Stall Booking System"

งาน: จัด layout ด้านบนของแอปใหม่ (app header + แถวสถิติ/ปุ่มของหน้า Admin Builder) ให้โปร่ง อ่านง่าย ไม่เบียด
ทำเฉพาะ UI ห้ามเปลี่ยน logic, store, การบันทึกข้อมูล หรือสิทธิ์ของแต่ละบทบาท

ปัญหาปัจจุบัน (จากภาพหน้าจอที่กว้าง ~1350px):
- ป้ายสถานะ "Online" ถูกบีบจนตัวอักษรเรียงแนวตั้ง และมีข้อความ "ขนาดผัง" ลอยอยู่ใต้ป้ายนั้นโดยไม่เกี่ยวกัน
- แถวบน: โลโก้, ป้ายออนไลน์, แท็บ (Admin Builder, Members, ตรวจสลิป, บันทึกการทำงาน, รายงานรายได้,
  Customer Map), ปุ่มธีม, "การจองของฉัน", กระดิ่ง, "Owner tester001" อัดกันจนไม่มีช่องว่าง
- แท็บที่เลือกมีทั้งพื้นสีและขอบขาวหนา ดูหนักเกินไป
- แถวสอง: ชิปสถิติ 5 อัน (ทั้งหมด, ว่าง, จองแล้ว, ปิดบริการ, รายได้รวม) กับปุ่ม 20×20ม., ตั้งค่าการจอง,
  จัดการโซน, เพิ่มแผง, บันทึกผัง, รีเซ็ตผัง แย่งที่กัน ปุ่มแต่ละอันคนละสี ไม่มีลำดับความสำคัญ
- "รีเซ็ตผัง" เป็นลิงก์เล็กชิดขอบขวา ทั้งที่เป็นการกระทำอันตราย
- "เพิ่มแผง" และขนาดผัง (20×20ม.) ซ้ำกับแถบเครื่องมือบนผัง

ขั้นที่ 1: อ่านโค้ดก่อน (ห้ามเดาชื่อไฟล์)
- หา component ของ header และแถวสถิติ/ปุ่ม โดยค้นข้อความ "Admin Builder", "Customer Map", "ขนาดผัง",
  "รีเซ็ตผัง", "รายได้รวม", "Online" ใน src/
- หาว่าข้อความ "ขนาดผัง" ที่ลอยอยู่ใต้ป้าย Online มาจากไหน (น่าจะเป็น label ของปุ่ม 20×20ม. ที่หลุดตำแหน่ง
  หรือ element ที่ flex ดันไป) อธิบายสาเหตุในสรุป
- ทำตารางทุกปุ่ม/แท็บ/ชิป ใน header และแถวสอง: ชื่อ | เรียกฟังก์ชัน/route อะไร | บทบาทไหนเห็น
- ตรวจว่าแถบเครื่องมือบนผัง (CanvasToolbar หรือที่เทียบเท่า) มีปุ่มเพิ่มแผงและขนาดผังแล้วหรือยัง
- ห้ามตัดการกระทำใดทิ้ง ทุกอย่างต้องยังกดได้ (อาจย้ายที่)

ขั้นที่ 2: แยก component (ถ้ายังไม่แยก)
- src/components/layout/AppHeader.vue       : header ทุกหน้า
- src/components/layout/HeaderNavTabs.vue   : แท็บ + การย้ายเข้า "เพิ่มเติม ▾" เมื่อไม่พอที่
- src/components/layout/UserMenu.vue        : ชื่อผู้ใช้ + บทบาท + ธีม + ออกจากระบบ

- ถ้ามี component เหล่านี้อยู่แล้วจาก prompt ก่อน ๆ (เช่น mobile-tablet-ux) ให้แก้ของเดิม ห้ามสร้างซ้ำ
- component แสดงผลและ emit เท่านั้น logic อยู่ที่เดิม

ขั้นที่ 3: App header สูง 56px แถวเดียว แบ่ง 3 ส่วน
ใช้ grid: grid-template-columns: auto 1fr auto; gap 16–24px; padding ซ้ายขวา 16–24px
1) ซ้าย (แบรนด์):
   - ปุ่มโลโก้เดิม + ชื่อตลาด/แอป (truncate ถ้ายาว, max-width ~180px, title= ชื่อเต็ม)
   - สถานะเชื่อมต่อ: เปลี่ยนจากป้าย "Online" เป็นจุดกลม 8px ข้างชื่อ
     ออนไลน์ = จุดเขียว + tooltip/aria-label "เชื่อมต่อแล้ว"
     ออฟไลน์ = จุดแดง + ป้ายข้อความ "ออฟไลน์" แนวนอน (เห็นเฉพาะตอนมีปัญหา เพราะตอนนั้นสำคัญ)
   - ลบข้อความ "ขนาดผัง" ที่ลอยอยู่ (ย้ายไปเป็น label ที่ถูกต้องในขั้นที่ 4)
2) กลาง (แท็บ):
   - แท็บสูง 36px, ไอคอน 16px + ป้าย, whitespace-nowrap ทุกแท็บ
   - แท็บที่เลือก: พื้นสีหลักแบบอ่อน (เช่น bg-primary/15) + ตัวอักษรสีหลัก + เส้นใต้ 2px หรือพื้นทึบอย่างใดอย่างหนึ่ง
     ห้ามมีขอบขาวหนา, แท็บอื่น: ตัวอักษรสีรอง พื้นโปร่ง, hover พื้นจาง ๆ
   - ป้ายภาษาไทยให้สม่ำเสมอ (เลือกแบบเดียวทั้งชุด ถ้าเดิมผสมอังกฤษ/ไทย ให้เสนอชุดไทยในสรุปแต่เปลี่ยนเฉพาะที่
     ไม่กระทบ route/test): เช่น ผังตลาด (Admin Builder), สมาชิก, ตรวจสลิป, บันทึกการทำงาน, รายงานรายได้, แผนที่ลูกค้า
   - ตรวจสลิป: ถ้ามี store นับสลิปรอตรวจอยู่แล้ว ให้แสดง badge ตัวเลข (ถ้าไม่มี ข้าม ห้ามสร้าง query ใหม่)
   - ใช้ ResizeObserver วัดพื้นที่: ไม่พอ -> ซ่อนป้ายเหลือไอคอน + tooltip ก่อน -> ยังไม่พอ -> แท็บท้าย ๆ ย้ายเข้า
     เมนู "เพิ่มเติม ▾" (แท็บที่เลือกอยู่ต้องเห็นเสมอ ห้ามถูกย้ายเข้าเมนู)
3) ขวา (ส่วนตัว):
   - "การจองของฉัน" ปุ่ม ghost มีไอคอน (จอกลางเหลือไอคอน + tooltip)
   - กระดิ่ง ปุ่มไอคอน 36×36 มี badge
   - เมนูผู้ใช้: วงกลมอักษรย่อ + ชื่อ + ▾ (บทบาท Owner แสดงเป็นบรรทัดเล็กในเมนู หรือ badge เล็กไม่เกิน 1 คำ)
     ในเมนู: ชื่อเต็ม, บทบาท, สลับธีม สว่าง/มืด (ย้ายปุ่ม ☀ มาไว้ที่นี่), ออกจากระบบ
- ทุกปุ่มใน header สูงเท่ากัน 36px มุมโค้งเท่ากัน ระยะห่างระหว่างปุ่ม 8px
- header พื้นทึบ มีเส้นขอบล่าง 1px สีจาง, sticky top-0

ขั้นที่ 4: Page bar ของหน้า Admin Builder สูง 48px แถวเดียว (แทนแถวชิป + ปุ่มเดิม)
1) ซ้าย: ชื่อหน้า "ผังตลาด" (font-semibold) + สถิติแบบข้อความเรียงเดียว คั่นด้วย " · "
   "1 แผง · ● ว่าง 1 · ● จองแล้ว 0 · ● ปิดบริการ 0 · รายได้ ฿0"
   - จุดสีเล็กหน้าแต่ละสถานะ ใช้สีเดียวกับ legend บนผัง ตัวเลข font-semibold tabular-nums
   - ไม่ใช้กล่องชิปที่มีขอบ/พื้นสีทีละอัน (นั่นคือสิ่งที่ทำให้แน่น)
   - ถ้าที่ไม่พอ: ย่อเหลือ "1 แผง · ว่าง 1 ▾" กดแล้วเปิด popover แสดงครบ
2) ขวา: ลำดับความสำคัญชัดเจน มีปุ่มเด่นแค่อันเดียว
   - ปุ่มรอง (ghost, สีเดียวกันหมด ไม่ใช่คนละสี): "⚙ ตั้งค่าการจอง", "◫ จัดการโซน"
   - ปุ่ม "⋯" เมนูเพิ่มเติม:
       ขนาดผัง 20×20ม. (เฉพาะถ้าแถบเครื่องมือบนผังยังไม่มี ถ้ามีแล้วให้ลบออกจากแถวนี้)
       ── เส้นคั่น ──
       รีเซ็ตผัง (ตัวอักษรสีแดง อยู่ล่างสุด กดแล้วต้องมี dialog ยืนยันเหมือนเดิมหรือเพิ่มถ้ายังไม่มี)
   - สถานะการบันทึก ก่อนปุ่มบันทึก: "● ยังไม่บันทึก" (สีเหลือง/ส้ม) หรือ "บันทึกแล้ว" (สีรอง)
     ใช้ state dirty ที่มีอยู่ ถ้าไม่มีให้ข้าม ห้ามสร้างระบบติดตามใหม่
   - ปุ่มหลัก "💾 บันทึกผัง" สีหลัก ปุ่มเดียวที่ทึบ
   - "เพิ่มแผง": ถ้าแถบเครื่องมือบนผังมีอยู่แล้ว ลบออกจากแถวนี้ ถ้ายังไม่มี ให้ย้ายไปไว้ในแถบเครื่องมือบนผัง
     (อย่าให้มีสองที่)
- ปุ่มทั้งหมดสูง 32px, padding แนวนอน 12px, ระยะห่าง 8px, ระหว่างกลุ่มรองกับปุ่มบันทึก 16px
- สไตล์ปุ่มมีแค่ 3 แบบ: primary (บันทึก), ghost (อื่น ๆ), danger-text (รีเซ็ต ในเมนู)
- page bar มีเส้นขอบล่าง 1px และพื้นต่างจาก header เล็กน้อยเพื่อแยกชั้น

ขั้นที่ 5: จอกลางและมือถือ
- 768–1279px: แท็บเหลือไอคอน + ป้ายสั้น/ไอคอนล้วน + tooltip ตามขั้นที่ 3, ปุ่มรองใน page bar เหลือไอคอน + tooltip,
  สถิติย่อตามขั้นที่ 4
- <768px: ใช้แบบ header มือถือจาก mobile-tablet-ux ส่วน 2 (แบรนด์ + กระดิ่ง + ☰, แท็บไปอยู่ในลิ้นชักหรือ bottom nav)
  ถ้ายังไม่ได้ทำ ให้ทำแบบขั้นต่ำ: แท็บทั้งหมดย้ายเข้าเมนู ☰
  page bar: [สถิติ ▾] [● สถานะ] [บันทึก] ที่เหลืออยู่ใน ⋯
- ทุกความกว้าง: ห้ามตัดบรรทัดกลางคำ, ห้ามตัวอักษรเรียงแนวตั้ง, ห้าม scrollbar แนวนอน
  (ใส่ whitespace-nowrap และ min-width: 0 / shrink-0 ให้ถูกที่ ป้ายสถานะห้ามมีความกว้างคงที่ที่เล็กกว่าข้อความ)

ขั้นที่ 6: เข้าถึงได้และ dark mode
- header ใช้ <header>, แท็บอยู่ใน <nav aria-label="เมนูหลัก">, แท็บที่เลือกมี aria-current="page"
- ปุ่มไอคอนล้วนทุกปุ่มมี aria-label และ tooltip ภาษาไทย (hover และ focus)
- เมนู "เพิ่มเติม", "⋯", เมนูผู้ใช้: ใช้ <Teleport to="body">, Esc ปิด, คลิกนอกปิด, ลูกศรขึ้นลงเลือก, คืน focus ให้ปุ่ม
- จุดสถานะออนไลน์ต้องมีข้อความสำหรับ screen reader (sr-only) ไม่ใช่สีอย่างเดียว
```
