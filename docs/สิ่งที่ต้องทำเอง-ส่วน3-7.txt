สิ่งที่คุณต้องทำเอง หลังทำส่วน 3-7 เสร็จ
========================================
(ผม commit โค้ดให้แล้ว แต่ไม่ได้ push และไม่ได้ deploy ตามกติกา)

ลำดับที่แนะนำ ทำตามเลขจากบนลงล่าง

1) สำรอง rules ที่ใช้อยู่จริงก่อนทับ
   - Firebase Console > Firestore Database > Rules > copy ทั้งหมด
   - เก็บที่ docs/rules-deployed-<วันที่>.rules (และเทียบกับ firestore.rules ใน repo)
   - จด Hosting release ปัจจุบัน (Console > Hosting > Release history)

2) Deploy "ในคำสั่งเดียว" (ห้ามแยก rules กับ hosting)
       npm run build && firebase deploy --only firestore:rules,firestore:indexes,hosting
   (หรือ npm run deploy ซึ่งทำเหมือนกัน)

3) รอ index ใหม่เป็น Enabled
   Console > Firestore > Indexes ต้องมี bookingLocks (stallId, date) และ (roundId, date)
   ก่อนหน้านั้นหน้าจองจะขึ้น "ดัชนียังสร้างไม่เสร็จ"

4) ตั้งค่าหลัง deploy (เข้าเป็น admin/owner > ปุ่ม "ตั้งค่าการจอง")
   - เวลากันแผงรอสลิป (ค่าเริ่มต้น 30 นาที) / เวลาส่งสลิปใหม่ (24 ชม.)
   - นโยบายยกเลิก: คืนเต็มก่อนวันขาย 3 วัน, น้อยกว่านั้นคืน 50%, วันขายไม่คืน
   - ข้อมูลบนใบเสร็จ: ชื่อตลาด ที่อยู่ เบอร์โทร เลขผู้เสียภาษี (ไม่บังคับ) ขนาดกระดาษ A5/A4
   - รอบตลาด / วันเปิดขาย (ถ้ายังไม่ได้ตั้งจากส่วน 2)

5) ทดสอบในเบราว์เซอร์จริง 1 รอบ (ผมยังไม่ได้เปิดดู — ไม่มี Playwright ใน repo และไม่ได้เพิ่ม dependency)
   ก. จองโดยไม่แนบสลิป > เห็นนับถอยหลังใน "การจองของฉัน" > อีกเครื่องเห็นแผงสีเหลือง
      (ถ้าไม่อยากรอ 30 นาที: ตั้งเวลากันแผงเป็น 10 นาทีขั้นต่ำ) ครบเวลาแล้วอีกเครื่องเห็นแผงว่างเอง และจองทับได้
      เครื่องแรกกดแนบสลิปต้องขึ้น "หมดเวลาแล้ว"
   ข. จอง 2 วัน แนบสลิป > admin อนุมัติ > ได้เลขใบเสร็จ R2569-000001 > อนุมัติอีกรายการได้เลขต่อกัน
   ค. เปิดใบเสร็จบน iPhone > "บันทึกเป็น PDF / พิมพ์" > ถ่างนิ้วที่ตัวอย่าง > แชร์ > บันทึกลงไฟล์
      ตรวจว่าภาษาไทยไม่เพี้ยน และอยู่หน้าเดียวขนาด A5
   ง. ผู้เช่าขอยกเลิกการจองที่อนุมัติแล้ว > admin อนุมัติ (ดูยอดแนะนำ) > แผงว่างบนผัง
      > บันทึกคืนเงินพร้อมรูปสลิป > ผู้เช่าเห็น "คืนเงินแล้ว" > ใบเสร็จมีลายน้ำ "ยกเลิก"
   จ. owner เปิด "รายงานรายได้" > ยอดตรงกับที่นับมือ > ส่งออก Excel เปิดใน Excel และ Google Sheets
      ตรวจว่าภาษาไทยถูก ตัวเลขรวมได้ วันที่เป็นวันที่จริง (ผมเช็คไฟล์ว่าเป็น zip/XML ถูกต้องแล้ว
      แต่ยังไม่เคยเปิดใน Excel จริง) ทดสอบดาวน์โหลดบน iPhone/iPad (แอปไฟล์)
   ฉ. admin (ไม่ใช่ owner) ต้องไม่เห็นเมนู "รายงานรายได้"
   ช. "บันทึกการทำงาน" ต้องมีทุกขั้นตอนข้างบน (รวม ส่งออกรายงาน, ออกเลขใบเสร็จ, หมดเวลา)

6) บอกผู้ใช้ให้ปิดแล้วเปิดแอปใหม่ / ล้าง cache บน iPad และมือถือ

7) ตัดสินใจเรื่องที่ยังเปิดอยู่
   - ยกเลิกหลายรายการพร้อมกันตามวัน (ตลาดปิดทั้งวัน): ผมยังไม่ได้ทำ (prompt อนุญาตให้แยกทำทีหลัง)
     ตอนนี้ใช้ "ยกเลิกการจองนี้ (ผู้ดูแล)" ทีละรายการ
   - ปุ่มดาวน์โหลด PDF ใบเสร็จโดยตรง: ต้องเพิ่ม library และฝังฟอนต์ไทย ถ้าต้องการให้บอก
   - log เรื่อง "ตั้งค่าตลาด" ทำแล้ว แต่ log "เปิด/ปิดแผง" ยังไม่ทำ เพราะอยู่ในโค้ดบันทึกผังที่ห้ามแตะ
   - แจ้งเตือนถึง admin เมื่อมีคำขอยกเลิก: ทำไม่ได้ตาม rules เดิม (แจ้งเตือนสร้างได้เฉพาะ admin)
     ใช้ป้ายตัวเลขบนเมนู "ตรวจสลิป" แทน ถ้าต้องการแจ้งเตือนจริงต้องแก้ rules notifications
   - การจองแบบเดิมที่ยังกันแผงด้วย stall.status: ปล่อยแผงเมื่อไร (admin ใช้ "ยกเลิกการจองนี้" ได้)

8) โควตา Spark: ถ้าผู้ใช้เกิน ~300 คน/วัน ที่เปิดแอปบ่อย การอ่านอาจเกิน 50,000/วัน
   (รายละเอียดใน docs/deploy-missing-systems.md) ให้ดู Console > Usage หลังเปิดใช้จริง 2-3 วัน

9) ไฟล์ prompt/missing-systems-th.md ยังไม่ถูก commit เหมือนเดิม ตัดสินใจเองว่าจะ commit หรือไม่
