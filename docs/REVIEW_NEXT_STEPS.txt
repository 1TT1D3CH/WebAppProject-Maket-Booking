-------------------------------------------------------------------------------
 ที่แก้ไปแล้วจากรายงานเดิม
-------------------------------------------------------------------------------
  - firestore.rules เขียนใหม่ มี role จริง (owner/admin/tenant)
  - users อ่านได้เฉพาะเจ้าของและ admin
  - bookings อ่านได้เฉพาะเจ้าของรายการและ admin
  - notifications แต่ละคนเห็นเฉพาะของตัวเอง
  - เพิ่ม .gitignore แล้ว และ build ล้มเมื่อไม่มี .env ครบ
  - modal ตั้งค่า Firebase / Local Mode ซ่อนใน production
  - หน้า login ไม่แสดงคำว่า "ชื่อผู้ใช้" แล้ว (ล็อกอินด้วยอีเมล)

-------------------------------------------------------------------------------
 สิ่งที่ควรทำต่อ (เรียงตามความสำคัญ)
-------------------------------------------------------------------------------

1. เลิก track .env, node_modules, dist ใน git                      [สำคัญสุด]
   - ตอนนี้ git ยัง track node_modules 8,292 ไฟล์, .env และ dist/
   - .gitignore ไม่มีผลกับไฟล์ที่ track อยู่แล้ว
   - คำสั่ง: git rm -r --cached node_modules dist .env  แล้ว commit
   - สถานะ git ยุ่ง: มี conflict (UD) ที่ dist/index.html และ node_modules/.bin/*
     ควรตรวจ staged ก่อนทำ

2. Commit งานที่ค้างอยู่
   - ไฟล์ใน src/, firestore.rules, firebase.json, package.json แก้แล้วแต่ยังไม่ commit
   - ไฟล์ .md ถูกย้ายเข้า prompt/ แต่ของเดิมยังขึ้นเป็น deleted
   - เสี่ยงงานหาย

3. Deploy rules และ hosting
   - npm run deploy
   - เว็บที่ขึ้นอยู่ยังเป็น build เก่า
   - หลัง deploy เปิดใน Incognito ทดสอบ ต้องไม่เห็น modal ตั้งค่า Firebase

4. ช่องโหว่การจองที่ rules ยังกันไม่ได้
   - markets/{id} ให้ผู้ใช้ที่ล็อกอินทุกคนแก้ฟิลด์ stalls ได้
   - tenant ที่รู้วิธีสามารถยกเลิก/แก้การจองของคนอื่นผ่าน console ได้
   - ทางแก้จริง: Cloud Function หรือแยก stall เป็น collection รายแผง

5. บั๊กในรายงานเดิมที่ต้องตรวจซ้ำว่าแก้แล้วหรือยัง
   - C4-C6: บันทึกผังของ admin เขียนทับการจองของลูกค้า / snapshot ใหม่ทับงานที่ยังไม่บันทึก
   - C7: บันทึกการจองล้มเหลวแต่ UI แจ้งว่าสำเร็จ
   - D1: การจองไม่มีวันที่/ช่วงเวลา (จำเป็นถ้าตลาดเปิดหลายวัน)
   - D2: สลิปโอนเงินไม่ถูกเก็บจริง

6. เพิ่ม test (ตอนนี้ package.json ไม่มี test เลย)
   - unit test: toLoginEmail, marketStore (การจอง/ตรวจแผงซ้ำ)
   - test ของ firestore rules ด้วย emulator

7. เรื่องเล็ก
   - README ให้ seed ด้วย --username (ตรงกับระบบ)
   - ถ้าจะให้ผู้ใช้ทั่วไปล็อกอินด้วย username ต้องออกแบบเพิ่ม เช่น เก็บ username
     ตอนสมัครแล้วหาอีเมลผ่าน Cloud Function (ห้ามเปิดอ่าน users สาธารณะ)
